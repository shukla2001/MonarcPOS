Standard Operating Procedure (SOP) • Deployment Manual

This official deployment manual provides end-to-end technical procedures for running Monarc POS locally in development/kiosk environments and deploying it in production to Hostinger VPS mapped to admin.monarcicecreams.com.

💻 PART 1: Local Machine Execution Procedure

Option A: Instant Setup with Docker Compose (Recommended)

  1. Ensure Docker Desktop is installed and running on your system.
  2. Open your terminal and navigate to the project directory: 
    cd MonarcPOS
  3. Start the multi-container environment (PostgreSQL, Backend API, Frontend SPA): 
    docker-compose up --build -d
  4. Seed the default administrator, cashier accounts, and menu catalog: 
    docker exec -it monarc_pos_backend npx prisma db seed
  5. Access the local kiosk:
    • POS Kiosk & Admin UI: http://localhost (Port 80)
    • Backend REST API: http://localhost:5000/api

Option B: Local Setup with Node.js & Local/Cloud PostgreSQL

  1. Backend Initialization: 
    cd MonarcPOS/backend
npm install
npx prisma db push
npm run prisma:seed
npm run dev
    Server runs on http://localhost:5000
  2. Frontend Initialization (In a new terminal window): 
    cd MonarcPOS/frontend
npm install
npm run dev
    Frontend UI opens at http://localhost:3000

☁️ PART 2: Hostinger VPS Production Deployment Guide

Target Production Domain: admin.monarcicecreams.com

Step 1: Connect to your Hostinger VPS

ssh root@YOUR_HOSTINGER_SERVER_IP

Step 2: Install Node.js 20, Nginx, Git & PostgreSQL

# Update OS packages
sudo apt update && sudo apt upgrade -y

# Install Git, Curl, Nginx, and Process Manager (PM2)
sudo apt install git curl nginx -y
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install -y nodejs
sudo npm install -g pm2

# Install PostgreSQL Server
sudo apt install postgresql postgresql-contrib -y

Step 3: Create PostgreSQL Production Database & User

sudo -u postgres psql

-- Run in PostgreSQL Shell:
CREATE DATABASE monarc_pos;
CREATE USER monarc_user WITH ENCRYPTED PASSWORD 'StrongProductionPassword2026!';
GRANT ALL PRIVILEGES ON DATABASE monarc_pos TO monarc_user;
\q

Step 4: Clone Code & Configure Production Backend

cd /var/www
git clone <YOUR_GIT_REPO_URL> monarc-pos
cd monarc-pos/backend
npm install

# Create environment configuration
cat <<EOF > .env
DATABASE_URL="postgresql://monarc_user:StrongProductionPassword2026!@localhost:5432/monarc_pos?schema=public"
PORT=5000
JWT_SECRET="monarc_royal_jwt_production_secret_998877665544332211"
NODE_ENV="production"
EOF

# Run Prisma schema push, seed database, and build
npx prisma generate
npx prisma db push
npm run prisma:seed
npm run build

# Start backend service with PM2
pm2 start dist/server.js --name "monarc-backend"
pm2 save
pm2 startup

Step 5: Build Frontend for Production

cd /var/www/monarc-pos/frontend
npm install

# Set production API URL
echo 'VITE_API_URL="https://admin.monarcicecreams.com/api"' > .env.production

# Build optimized static distribution
npm run build

Step 6: Configure DNS in Hostinger hPanel

  1. Log in to Hostinger hPanel.
  2. Navigate to Domains → Select monarcicecreams.com → DNS / Nameservers.
  3. Create an A Record:
    • Type: A
    • Name: admin
    • Points to: YOUR_HOSTINGER_SERVER_IP
    • TTL: 14400

Step 7: Configure Nginx Virtual Host

sudo nano /etc/nginx/sites-available/admin.monarcicecreams.com

Paste the following Nginx block:

server {
    listen 80;
    server_name admin.monarcicecreams.com;

    # Frontend Static React App
    root /var/www/monarc-pos/frontend/dist;
    index index.html;

    location / {
        try_files \$uri \$uri/ /index.html;
    }

    # Backend Express REST API
    location /api/ {
        proxy_pass http://localhost:5000/api/;
        proxy_http_version 1.1;
        proxy_set_header Upgrade \$http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host \$host;
        proxy_set_header X-Real-IP \$remote_addr;
        proxy_set_header X-Forwarded-For \$proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto \$scheme;
        proxy_cache_bypass \$http_upgrade;
    }
}
# Enable site and test configuration
sudo ln -s /etc/nginx/sites-available/admin.monarcicecreams.com /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl restart nginx

Step 8: Activate Free SSL Certificate (HTTPS)

sudo apt install certbot python3-certbot-nginx -y
sudo certbot --nginx -d admin.monarcicecreams.com
✨ Verification: Open https://admin.monarcicecreams.com in any browser. Log in with admin / Admin@123 to access your live store management portal!
